Research

I want robots to work with the soft, shifting objects that homes and factories are full of.

MSc thesisIn progress

UCAT-IL: Uncertainty-Aware Contact and Topology-Guided Imitation Learning from Monocular Human Demonstrations for Deformable Object Manipulation

A robot watches a person handle an object on ordinary single-camera video, and learns to do the same, even when the object is a rope or a piece of cloth that never holds one shape.

Read the thesis documentation
Imitation learning from video
Learning manipulation skills from one ordinary camera, with no motion-capture gloves or teleoperation rig.
Deformable objects
Rope, cloth and other soft things have no fixed shape, so the robot has to track how the object changes as it moves.
Contact and topology
Where hands touch an object, and how its structure changes through loops, crossings and folds, guides the next action.
Uncertainty awareness
Knowing when a reading of the video cannot be trusted, so the robot can hold back instead of guessing.
